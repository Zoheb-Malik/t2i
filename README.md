# t2i.zohebmalik.com (Text To Image by Zoheb Malik)

<!-- dash-content-start -->

Generate images based on text prompts using [Workers AI](https://developers.cloudflare.com/workers-ai/). This is a modified worker that allows you to input custom prompts directly from the website, using the `@cf/stabilityai/stable-diffusion-xl-base-1.0` model.
